# PETRA v0.1.0

Release status: candidate — not yet published.

## Summary

PETRA is packaged independently as a prime/exponent interpretation
layer over the SHAPES structural core.

PIP belongs to PETRA. The initial maintained executable
interpretation policy is LRPE.

## Package

- Distribution: `petra-interpretation`
- Version: `0.1.0`
- Proposed Git tag: `petra-v0.1.0`
- Python: `>=3.10`
- Dependency: `agnostic-shapes-core>=4.0.0,<5.0.0`

This is the initial standalone distribution version, not a
renumbering of historical PETRA releases.

## Verification

Wheel and sdist isolation, clean installation, PETRA tests,
static checks, and GitHub CI have passed during preparation.

## Publication boundaries

ASHES 4.0.0 must be published and its artifact dependency
verified before PETRA is released.

PyPI publication has not been established.

No standalone PETRA Zenodo DOI is assigned in this candidate.

Historical PETRA provenance must be preserved.
