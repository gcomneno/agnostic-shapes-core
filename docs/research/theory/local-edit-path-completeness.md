# Completeness of local witnessed-edit path relations

Status: research theorem; mathematical proof proposed and internally reviewed.
Scope: SHAPES structural carrier and its elementary witnessed edits.
Authority: research only; no normative SPEC or runtime promotion.

## 1. Mathematical setting

Let P be the set of isomorphism classes of finite nonempty rooted
unordered trees, with intrinsic child multiplicity.

Write Z for the unique one-node form.

Let W_P be the directed multigraph of elementary witnessed ADD and
REMOVE edits, using the witnessed-edge isomorphism classes defined in
`meta-presentations-rewrite-relations.md`.

An elementary ADD attaches one fresh leaf to an existing occurrence.
An elementary REMOVE deletes one non-root leaf.

Every witnessed edge e has an involutive reverse e^{-1}.

Let equiv_loc be the least path congruence generated by:

1. e ; e^{-1} = id and e^{-1} ; e = id;
2. a ; (b/a) = b ; (a/b) for the existing independent-edit squares.

In particular, two REMOVE operations at distinct leaf occurrences
of a common concrete realization satisfy the independence criterion.

No stronger independence condition is assumed.

## 2. Main theorem

### Theorem — Endpoint completeness

For all forms P and Q, and all witnessed edit paths p,q : P -> Q,

    p equiv_loc q.

Consequently, inverse cancellation and REMOVE/REMOVE independent-edit
commutation already generate every witnessed-path equality determined
solely by the source and target forms.

The result concerns the symmetric path congruence, in which relations
may be applied in either direction.

## 3. Lemma — Uniqueness of complete REMOVE paths modulo local relations

For every form P, all REMOVE-only witnessed paths P -> Z are
equivalent under REMOVE/REMOVE independent commutation.

### Proof

Proceed by induction on n = size(P).

For n = 1, P = Z, and the only REMOVE-only path is empty.

Suppose n > 1. Let

    d = r ; d'
    h = s ; h'

be two REMOVE-only paths from P to Z.

If r = s as witnessed-edge classes, their target form is the same.
The induction hypothesis applied to that smaller target gives
d' equiv_loc h', hence d equiv_loc h.

Otherwise r and s are distinct witnessed-edge classes.

Choose a single concrete realization T of P. Transport representatives
of r and s to T using rooted realization isomorphisms.

Let x and y be their respective removable leaf occurrences.

They must be distinct: the same leaf occurrence in the same realization
defines the same witnessed REMOVE edge class.

Removing x does not destroy or change the removability of y, and
vice versa. The existing REMOVE/REMOVE independence criterion therefore
supplies a commuting square

    r ; s_r equiv_loc s ; r_s,

where s_r and r_s are the corresponding transported removal witnesses.

Both length-two paths terminate at the same form U, obtained by
removing x and y from T.

Choose any REMOVE-only path t : U -> Z.

By induction at the two smaller one-step target forms,

    d' equiv_loc s_r ; t
    h' equiv_loc r_s ; t.

Congruence and the commuting square now yield

    d
    = r ; d'
    equiv_loc r ; s_r ; t
    equiv_loc s ; r_s ; t
    equiv_loc s ; h'
    = h.

Thus every pair of complete REMOVE paths from P is locally equivalent.
QED.

## 4. Lemma — Compatibility of a canonical reduction with every edit

For each form X, choose a REMOVE-only path

    rho_X : X -> Z,

with rho_Z the empty path.

For every witnessed elementary edge e : X -> Y,

    e ; rho_Y equiv_loc rho_X.

### Proof

If e is REMOVE, both e ; rho_Y and rho_X are REMOVE-only paths
from X to Z. Section 3 applies.

If e is ADD, its reverse e^{-1} : Y -> X is REMOVE. Thus both
rho_Y and e^{-1} ; rho_X are complete REMOVE paths from Y to Z.

By Section 3,

    rho_Y equiv_loc e^{-1} ; rho_X.

Precomposition with e and inverse cancellation give

    e ; rho_Y
    equiv_loc e ; e^{-1} ; rho_X
    equiv_loc rho_X.

QED.

## 5. Proof of the main theorem

Let p : P -> Q be an arbitrary finite witnessed edit path.

Repeated application of Section 4 along its successive edges gives

    p ; rho_Q equiv_loc rho_P.

The reverse path rho_Q^{-1} exists by involutive reversal of
elementary witnesses.

Using inverse cancellation and congruence,

    p
    equiv_loc p ; rho_Q ; rho_Q^{-1}
    equiv_loc rho_P ; rho_Q^{-1}.

The resulting representative depends only on P and Q.

Therefore, for any two paths p,q : P -> Q,

    p equiv_loc rho_P ; rho_Q^{-1} equiv_loc q.

This establishes endpoint completeness. QED.

## 6. Consequences

### Corollary 1 — Thin connected groupoid

The path quotient by equiv_loc is a connected thin groupoid:
between any two forms there is exactly one arrow class.

Existence follows from REMOVE reduction to Z followed by the
reverse of a REMOVE reduction from the target.

Uniqueness follows from the main theorem.

Equivalently, the quotient is the pair groupoid on the set P.

### Corollary 2 — Closed-path triviality

Every witnessed closed edit path p : P -> P satisfies

    p equiv_loc id_P.

Thus backtracks and the admitted independent-edit squares generate
all closed-path equivalences in the precise path-congruence sense.

No separate assertion about graph-theoretic simple cycles,
a specific square-complex construction, or CAT(0) geometry follows.

## 7. Mathematical boundaries

The proof uses only:

- finiteness and rooted-tree structure;
- existence of removable non-root leaves;
- involutive reversal of witnessed elementary edits;
- the existing REMOVE/REMOVE independence square;
- ordinary congruence closure.

It does not require ADD/ADD or mixed independent-edit squares.

It does not require a total residual operation on pairs of
automorphism-quotiented witnessed-edge classes.

The simultaneous removal square is constructed using representatives
on one concrete realization. This does not define a residual function
on arbitrary pairs of individual witnessed-edge classes.

The result does not preserve occurrence-survivor correspondence.

For example, REMOVE followed by reverse ADD is congruent to
the identity, although the deleted occurrence is replaced by a
fresh occurrence in a concrete realization.

Hence the TPI fixed-witness survivor relation does not factor
faithfully through this endpoint-complete path quotient.

The theorem does not establish:

- reconstruction of edit history;
- preservation of TPI survivor witnesses;
- a terminating or confluent oriented normalization algorithm;
- a total Bruggink-style residual system;
- global rigidity of the unpointed edit graph;
- originality or priority relative to the mathematical literature;
- changes to SHAPES normative semantics or implementation.
