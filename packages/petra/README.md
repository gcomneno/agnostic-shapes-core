# PETRA

Independent prime/exponent interpretation project over ASHES.

PIP and LRPE belong to PETRA, not to the SHAPES structural core.

The initial standalone distribution version is provisionally `0.1.0`.
It depends on `agnostic-shapes-core>=4.0.0,<5.0.0`.

For local development from the repository root:

```bash
pip install -e .
pip install -e ./packages/petra
```

Publication requires the gates defined in
`../../docs/releases/independent-distributions.md`.

Normative specification currently resides at:
`../../docs/reference/PETRA.md`.
